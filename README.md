Analyses of questionnaire data collected in the Avian Contact Study, an online survey to gather data on human contact with birds and knowledge of avian influenza to understand avian influenza transmission.

This branch contains code for the analyses underpinning the manuscript titled ‘Controlling avian influenza spillover events: a modelling study’ by Izel Avkan, Suzanne Gokool, Louise E. Smith, Genevieve Clapp, Rachel Cox, Amy Thomas, and Ellen Brooks-Pollock. doi: https://doi.org/10.1101/2025.07.22.25331905.

The ‘script’ folder contains R Markdown (.Rmd) files for running the branching process model and generating the figures in the manuscript. To generate figures, you can either use the pre-saved .Rds files in the ‘outbreak_datasets’ folder, or generate new outbreak datasets with your chosen parameters by first running the model, then the files in the ‘generate_outbreak_data’ folder.
